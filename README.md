**Data Analyst & Data Scientist** · B.S. in Geophysical Engineering · Arequipa, Peru

I use data to help operations spend less and decide better. I come from geophysics, where I learned to check the quality of measurements and find anomalies; today I apply that with Python, SQL and Machine Learning.

Before working formally in data, I was already using it on construction and logistics operations:
